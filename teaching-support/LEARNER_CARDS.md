# Independent learner task cards

Use a personal project copy. Keep completed solutions and AI tools closed. Your notes, compiler, WSDL/XSD and supplied setup files are allowed. Predict, write, test and explain. Work one card after its prerequisite lesson; the stated time is an observation window, not a speed grade.

## A — Java choices (15–20 minutes)

After Java basics: write a method returning `Keep practising` below a threshold and `Ready` at or above it. L1 uses threshold 5, L2 6, L3 7. Main prints calls for threshold minus one, threshold and threshold plus one. Explain the parameter, argument, return and branch in your code.

## B — HTTP and a repaired error (20–30 minutes)

After the HTTP lab: add GET `/room` returning your classroom. Preserve `/greeting`, missing-route handling and rejection of POST. Test all four cases with status/body evidence. In a copy of an introduction program, remove one semicolon, read the compiler error, repair it and explain the clue.

## C — real database work (25–35 minutes)

After 1.8B: save a fictional name (L1 Mira, L2 Chidi, L3 Bola), record the database file/id, close and read it in a new process. Commit a changed name, then try another change that flushes and rolls back. Read again in a new process. Find an absent id. Explain which name remained and why flush is different from commit.

## D — persistent REST (30–40 minutes)

After completing your BookResource in 2.13B: add an exact-title filter if you have not already implemented one. Your instructor gives two new titles. Save both; follow the returned Location, test filtering and a blank-title rejection, then restart the server and read the saved rows again. Record actual status/body, generated ids and unchanged rows after rejection. Explain the request, resource, store and transaction flow.

## E — SOAP transfer (35–45 minutes)

After Session 3: add `int calculatePrintingCost(int pages)` to the course SOAP service. L1 uses rate 4, L2 6, L3 8 in illustrative currency units per page. Permit 1–12 inclusive and use the declared application fault outside that range. Choose clear XML input/result names. Build/restart, inspect the updated WSDL/XSD, send matching raw SOAP and regenerate a typed client to call it. Test 1, 12, 0 and 13; explain the results and proxy flow.

## F — next-day recall (20–30 minutes)

The instructor selects two skills you completed and changes the names, rate, threshold or query value. Recreate the new behaviour without the finished example. Predict, test and explain; record any help used. If a skill is difficult, return to its smaller guided exercise and attempt another variation afterward.
